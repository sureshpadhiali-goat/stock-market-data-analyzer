# Screenshot and output checklist

Capture these from your actual run (do not use mock screenshots):
1. Project folder open in VS Code / File Explorer.
2. Raw sample CSV preview.
3. Terminal showing the selected data source and row count.
4. `outputs/closing_price.png`.
5. `outputs/moving_averages.png`.
6. `outputs/daily_returns.png`.
7. `outputs/volatility.png`.
8. Terminal analysis summary with return and volatility.
9. `reports/analysis_report.md` open in editor.
10. GitHub repository page showing README, source folders and commit history.

Suggested filenames: `01_project_structure.png`, `02_dataset_preview.png`, `03_terminal_run.png`, `04_closing_price.png`, `05_moving_averages.png`, `06_daily_returns.png`, `07_volatility.png`, `08_report.png`, `09_github_repo.png`.

Keep images in `images/` if they are curated documentation screenshots. Generated charts are stored in `outputs/` and ignored by Git by default; copy selected chart images to `images/` if you want them displayed in README.
